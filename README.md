# TinyLoop｜极简轮次计时器

一个为短任务设计的 Windows 10 x64 原生计时器：**3 分钟一轮，30 轮一组，结束后听一段轻音乐并休息**。单轮时长、每组轮数和休息时长都能修改。程序完全离线，窗口很小，切换到其他软件后也能用单键完成当前轮。

## 功能一览

- 单轮默认 **03:00**，大循环默认 **30 轮**，休息默认 **15:00**；均可在窗口内修改。
- 每轮到时或提前完成，响三声不同音高，记 1 次并自动开始下一轮；前 **336** 轮的三声组合不重复。
- 每组完成后，轮换播放 **4 段不同的原创轻音乐**，随后进入休息；休息结束后等待手动开启下一组。
- 前台按**空格**、其他软件中按 **F8** 提前完成；F8 被占用可切换 F9。支持暂停、撤销、系统托盘和本地记录。

## 使用

1. 三个数字都能在窗口底部修改，点击「应用设置」。修改时，正在进行的一轮或休息保留原时长，新值用于下一轮或下一次休息。
2. 点击「开始」。窗口在前台时按**空格**可提前完成；在其他软件中按 **F8** 也可提前完成。按住 F8 只算一次。F8 被占用时可在托盘右键菜单切换至 F9；程序仅在专注计时期间注册该全局键。
3. 每轮到时或提前完成，播放三声不同音高，响完记 1 次并自动开始下一轮。前 336 轮三声组合不重复，此后循环。第 30 轮结束后，轮换播放四段原创轻音乐之一（约 12.5 秒），然后开始休息倒计时。
4. 休息结束后响两声提示，停在待命界面；你点击「开始」才进入下一组。休息中可暂停。点击「撤销上次」会移除最后一轮记录；若正在休息，也会取消休息并回到专注计时。
5. 关闭窗口会隐藏到系统托盘；托盘右键可显示、暂停、撤销、切换 F8/F9 或真正退出。再次打开 `.exe` 会显示已有窗口。

休眠时正在进行的专注或休息会暂停；唤醒后需要点击「继续」。退出再打开会恢复为暂停状态。电脑关机、睡眠或静音时，软件无法保证声音准点播放。

## 本地文件

设置和记录在 `%LOCALAPPDATA%\TinyLoop\` 下：`settings.ini` 和 `events.log`。记录包含完成时间、计划和实际时长、自然到时或提前完成；撤销以单独事件写入。程序不读取键盘输入内容，不连接网络，不自动开机启动。要彻底移除，可退出程序后删除 `.exe` 和这个本地目录。

## 验收（Windows 10 x64）

- 将单个 `.exe` 放到一个不安装开发工具的 Windows 10 x64 电脑，断网启动；检查小窗口和托盘。
- 为加快验证，设单轮 `00:05`、轮数 `2`、休息 `01:00`。等第一轮到时，确认三声互异、今日次数变为 1 且第二轮自动开始；用 F8 提前完成第二轮，确认另一组三声、轻音乐、随后休息。
- 试两次大循环，确认轻音乐不同；休息倒计时结束后只待命，不自动开启下一组。
- 在记事本敲空格应正常输入文字，不会完成计时；本程序窗口前台按空格完成。长按 F8 只加一次。最小化到托盘再按 F8 也能完成。
- 休眠再唤醒，确认倒计时暂停且不批量补记；退出再启动检查记录与设置；测试撤销。
- 在任务管理器观察运行 1 小时后的内存和空闲 CPU，确认无持续增长。

当前自动化测试涵盖计时状态机、30 轮边界、暂停、撤销、336 组三声组合、四段轻音乐的不同波形。交付环境没有可运行的 Windows 图形会话，上述 Windows 10 实机项目需要在你的电脑上复验。

## 源码结构与构建

`timer_core.*` 是无平台计时状态机；`audio.*` 生成三声和轻音乐；`win_storage.*` 管理本地日志与设置；`win_main.c` 包含 Win32 窗口、托盘和热键。单个声音缓冲区重复使用，界面只在内容改变时刷新；没有网页框架、后台服务或第三方库。

- Linux 交叉构建：安装 GCC、MinGW-w64，然后执行 `bash build.sh`。脚本先跑核心测试，再输出 `dist/TinyLoop-Win10-x64.exe`。
- Windows 原生构建：使用 Visual Studio 2022 的 x64 Native Tools Command Prompt，运行 `build.cmd`。
